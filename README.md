# Alhambra - a minimal viable theme for WordPress 6.+

This theme is experimental and made for teaching block themes in multimedia designer classes. 

## Style variation: GreenMan

The styles in the present version is Greenman. A few blocks have been altered:

* Button background color
* Paragraph color changed
* etc.

Now this is part of theme.json too.

## Making the style variation

The theme.json was copyed as is and pasted to ./styles/

After renaming the file to GreenMan, the variation became part of the theme.
